# Судоку «Десять ступеней»

Мобильная судоку: 10 ступеней от «Разминки» до «Гроссмейстера», у каждой свой мир с заставкой, декорациями и анимациями.

- Каждая головоломка генерируется заново и имеет единственное решение
- Заметки, подсказки с объяснением хода, отмена и повтор, пауза, режим «сначала цифра»
- Головоломка дня с серией, 26 достижений, статистика по ступеням, звёзды
- Оформление меню в стиле любой открытой ступени
- Прогресс хранится в браузере (localStorage)

Вся игра — один файл `index.html`, без сборки и зависимостей. Открой его в браузере или задеплой как статический сайт.
